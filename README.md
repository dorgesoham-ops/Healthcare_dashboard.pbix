# Healthcare Dashboard – Power BI

This project is an interactive Healthcare Dashboard created using Power BI.

## Project Objective
The dashboard helps to analyze healthcare data and understand important information using charts, graphs, and KPIs.

## Tools Used
- Power BI
- Excel
- Power Query
- DAX
- Data Visualization

## Key Features
- Interactive dashboard
- Charts and graphs
- KPI cards
- Filters and slicers
- Healthcare data analysis

## Conclusion
This project converts healthcare data into meaningful visual insights and makes the data easy to understand.
